# Budgie changelog

| 2026-10-23 | qa-full | Save recipe is never greyed out: it says what's missing ("Almost there: give the recipe a name…") and jumps there. Import only adds: foods, logs, weigh-ins and settings you already have are never changed or lost. New "Add common foods to my library" button (white, whole wheat, rye, sourdough breads, bagels, pita, tortillas, cereals, grains, dairy, proteins, vegetables, fruit, nuts…) that skips foods you already have. Quick entry: Return on the keyboard adds it. QA: every button and field now has a test (coverage gate), use cases written, and each release report compares with the last one (regression check). | **Live** |
| 2026-10-23 | recipes-free | Recipes without AI: paste an ingredient list and tap Read ingredients. Built-in list of ~90 common foods, herbs and spices (USDA values) fills gaps in your library and joins it when you save. "From a photo" shows the free iPhone way: copy the text from the photo and paste it. | Replaced by qa-full |

Fix: the tap that reads what you said never saves before you've seen the review. | Replaced by recipes-free |
